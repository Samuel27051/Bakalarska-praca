# Unreal Engine – 2D Endless Runner (Blueprints)

Tento priečinok obsahuje zdrojový projekt hry vytvorenej v Unreal Engine s využitím Blueprint Visual Scripting.

## Charakteristika projektu
Hra je navrhnutá ako 2D endless runner, v ktorom hráč v podobe astronauta neustále postupuje dopredu, vyhýba sa prekážkam a snaží sa dosiahnuť čo najvyššie skóre.

## Implementované mechaniky
- neustály pohyb herného prostredia
- animované pozadie a zem pomocou materiálov
- mechanika skoku
- kolízny systém
- smrť hráča po zásahu
- Game Over obrazovka
- reštart po smrti
- skórovanie podľa vzdialenosti
- spawnovanie prekážok

## Požiadavky
- Unreal Engine 5.3 alebo novší

## Spustenie projektu
1. Otvorte Unreal Engine.
2. Zvoľte otvorenie existujúceho projektu.
3. Načítajte projekt z priečinka `UnrealEngine_Projekt`.
