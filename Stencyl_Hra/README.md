# Stencyl – Build hry

Tento archív obsahuje exportovanú verziu hry vytvorenej v nástroji Stencyl.

## Obsah
Súbor `Stencyl_Hra.zip` predstavuje build 2D endless runner hry vytvorenej pomocou blokového systému Stencyl.

## Spustenie
1. Stiahnite archív `Stencyl_Hra.zip`.
2. Rozbaľte jeho obsah.
3. Spustite hru podľa exportovaného formátu.

## Poznámka
Zdrojový projekt sa nachádza v priečinku `Stencyl_Projekt`.
