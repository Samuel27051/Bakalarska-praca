# Unity – Build hry

Tento súbor obsahuje odkaz na hrateľnú verziu hry vytvorenej v prostredí Unity.

## Odkaz na build
[Otvoriť / stiahnuť build hry](https://drive.google.com/file/d/16FOnATMCw0H3ONBdu42YDB14MX22Tpmg/view?usp=sharing)

## Charakteristika buildu
Build predstavuje exportovanú verziu 3D level-based runner hry vytvorenej v Unity pomocou Visual Scripting.

## Odporúčaný postup
1. Otvorte odkaz vyššie.
2. Stiahnite build hry.
3. Spustite exportovaný súbor hry.

## Poznámka
Zdrojový projekt sa nachádza v priečinku `Unity_Projekt`.
