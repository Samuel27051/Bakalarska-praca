# Unreal Engine – Build hry

Tento súbor obsahuje odkaz na hrateľnú verziu hry vytvorenej v Unreal Engine.

## Odkaz na build
[Otvoriť / stiahnuť build hry](https://drive.google.com/file/d/1ByUtI7MppgrSmJs3ui1L5NIAHL-hTFAz/view?usp=sharing)

## Charakteristika buildu
Build predstavuje exportovanú verziu 2D endless runner hry vytvorenej v Unreal Engine pomocou Blueprint systému.

## Odporúčaný postup
1. Otvorte odkaz vyššie.
2. Stiahnite build hry.
3. Spustite exportovanú verziu hry.

## Poznámka
Zdrojový projekt sa nachádza v položke `UnrealEngine_Projekt`.
