# GDevelop – Build hry

Tento súbor obsahuje odkaz na hrateľnú verziu hry vytvorenej v nástroji GDevelop.

## Odkaz na build
[Otvoriť / stiahnuť build hry](https://drive.google.com/file/d/1tRbpqzEe9_uYP4tUSViK5H1wyZ48m_p-/view?usp=sharing)

## Charakteristika buildu
Build predstavuje exportovanú verziu 2D endless runner hry vytvorenej v GDevelop.

## Odporúčaný postup
1. Otvorte odkaz vyššie.
2. Stiahnite build hry.
3. Spustite exportovanú verziu podľa formátu balíka.

## Poznámka
Zdrojový projekt sa nachádza v priečinku `GDevelop_Projekt`.
