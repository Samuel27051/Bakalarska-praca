# Construct 3 – 2D Endless Runner

Tento priečinok obsahuje zdrojový projekt hry vytvorenej v nástroji Construct 3. Projekt bol vytvorený ako súčasť bakalárskej práce zameranej na porovnanie no-code a low-code herných vývojových prostredí.

## Charakteristika projektu
Hra je navrhnutá ako 2D endless runner, v ktorom hráč prekonáva prekážky, zbiera mince a zvyšuje skóre.

## Implementované mechaniky
- pohyb hráča
- skok
- kolízie s prekážkami
- zber mincí
- aktualizácia skóre
- náhodné generovanie objektov
- reštart hry po kolízii

## Súbory
- `Hra.c3p` – hlavný projektový súbor Construct 3

## Požiadavky
- webový editor Construct 3 alebo desktop verzia Construct 3

Spustenie
1. Otvorte [Construct 3 editor](https://editor.construct.net)
2. Kliknite „Menu → Project → Open“
3. Vyberte súbor `Hra.c3p`

## Poznámka
Projekt využíva event-based systém nástroja Construct 3 bez potreby tradičného programovania.
